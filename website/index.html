隐私与安全底线

为儿童与家庭，筑牢每一道安全防线

技术服务于爱，更恪守责任边界。

系统凭据加密存储

API Key 仅在 Electron 主进程中读取并存入系统凭据存储，不写入故事项目、日志或导出的 HTML。

严格成年人声纹授权

在线复刻严格限制为成年人授权声音，不采集未成年人或公众人物声音，杜绝声纹滥用。

适龄内容安全边界

根据孩子年龄动态调整词汇复杂度与情绪深度，内置严格的内容安全过滤，无惊吓与暴力元素。

离线独立单文件便携

导出的 HTML 绘本不包含任何 API Key、草稿或原始声音样本，完全离线运行，安全无虞。
